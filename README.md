# Demonstração — catálogo para revendas

[**Abrir o site**](https://matheusmartinsidt.github.io/auto-loja-demo/)

[**Testar o painel pelo celular**](https://matheusmartinsidt.github.io/auto-loja-demo/#painel)

Modelo demonstrativo personalizável com catálogo, filtros e painel de veículos.

Os veículos e as fotos são ilustrativos. As alterações feitas no painel ficam apenas no navegador usado; não alteram o estoque para outras pessoas. Login e armazenamento online não fazem parte desta demonstração.

Este repositório contém a versão compilada usada para apresentação.
